# Contributing

Issues and pull requests are welcome, especially:
- measured |E*|, fatigue or rutting data for nano-modified mixtures that could replace the literature-bounded inputs;
- field sections that could calibrate the transfer functions;
- ports of the FE model to CalculiX or Code_Aster for comparison.

Please run `pytest -q` and `python run_all.py --selftest` before opening a pull request. Changes that alter any reported number should say so in the pull request and in `CHANGELOG.md`.
